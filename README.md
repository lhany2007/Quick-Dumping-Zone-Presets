Quick Stockpile Zones

A mod for players who find even setting up presets too bothersome.

This mod adds a right-click menu to the vanilla 'Dumping stockpile zone' designator, allowing you to instantly place 6 pre-configured zones without opening the filter tab.

Priority is automatically set to 'Important'.

Included Zones
Chunk Zone: Allows stone chunks, steel slag chunks, and mechanoid chunks.
Toxic Wastepack Zone: Allows only toxic wastepacks.
Corpse Zone: Allows all corpses.
Mechanoid Corpse Zone: Allows mechanoid and drone corpses.
Structure Zone: Allows all minified/packaged structures (entire Buildings category).
Butcher Zone: Allows only animals (no rotten). 

riority is automatically set to 'Critical'.
